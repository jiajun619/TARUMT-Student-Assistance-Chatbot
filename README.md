# TARUMT Student Assistance Chatbot

## Project Overview

This project is a TARUMT Student Assistance Chatbot developed using Natural Language Processing (NLP) and machine learning.

The chatbot supports common TARUMT-related enquiries such as:
- Admissions
- Timetables
- Examinations
- Fees
- Scholarships
- Programmes
- Campus facilities

Two machine learning classifiers are implemented:
- Logistic Regression
- Linear Support Vector Classification (LinearSVC)

## Requirements

- Python 3.11
- Streamlit
- pandas
- numpy
- scikit-learn
- joblib
- nltk
